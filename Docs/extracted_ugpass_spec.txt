ID Token Verification with JWKS Url
Description:
ID token received in token endpoint response is  JWT token which are signed with DAES private key. 
4.2.6.1
JWKS Request:
GET 
http

/
api/Jwks/jwksuri
4.2.6.2
Steps for validation of JWT token:
Need to decode the token, which is in JWT format.
The JSON Web Key S
et (JWKS) need to be retrieved from DAES Authorization Server and cached 
in application which is required for Signature verification.
Verify the token's signature by matching the key that was used to sign in with one of the keys 
retrieved from DAES Authori
zation Server's JWK endpoint. Specifically, each public key is 
identified by a kid attribute, which corresponds with the kid claim in the token header.
If the kid claim doesn't match, it's possible that the signing keys have changed. Try retrieving the 
key
s again from server.
The iss(issuer) claim should match with DAES Authorization Server Issuer Url.
The aud(audience) claim should match the Client ID that is used to request the ID Token, which 
is the Client ID of the SP.
The iat(issued at time) claim in i
d_token indicates when this token was issued, expressed in Unix 
time.
The exp (expiry time) claim in id_token is the time at which this token will expire., expressed in 
Unix time. Expired token is not valid.
The nonce claim value in id_token should 
match with nonce value that was passed when 
requested the ID token.
